=======
A2A API
=======

The optional A2A adapter serves an official ``a2a-sdk`` request handler on
native Litestar routes. Install ``litestar-mcp[a2a]`` to use it; see
:doc:`/usage/a2a` for the protocol, authorization and streaming rules.
